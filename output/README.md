# Green Memories v1.5.0 简体中文补丁

本地研究汉化，原始 ROM 保持不变。首次运行选第一项「简体中文」；原葡萄牙语入口保留，未把葡萄牙语全部重新翻译。汉化覆盖英文模式的剧情、任务、地图名、交互按钮、40种物品及说明，另外重绘中文菜单、八页天气教程、按键图、界面标签及营地招牌。游戏名、工作室品牌和官网网址保留原样。

## 使用

- 直接运行 `output/green_memories_zh.gba`。
- 或使用 `output/green_memories_zh.bps` 给自己的原始 ROM 打补丁。
- 只适用于用户提供的 Green-Memories-v1.5.0.gba，原始 SHA-256：`a5bf6ba5d6f78912e35986ba21cf034c65677cc66c3f97022606069dbaafb202`。
- 未读取或修改模拟器里的现有存档。游戏版本和存档结构未作主动更改；尚未验证现有长流程存档兼容性。

## 字体和编码

使用开源 Fusion Pixel 12px 原生点阵，16×16 透明字块、原色调文字和暗色阴影，避免把汉字挤进原版8px窄字框。七份 Butano 字体描述符扩展到同一套中文字符，原版拉丁字形与葡语重音字符保留。图片交付覆盖88个背景资源（含六个分类/顶栏图集）和4个营地招牌图块。文本交付包含1090条迁移文字、400个固定物品字段和132个短名字段，共1622个补丁字段（含重复语言分支、物品短表，非1622句独立剧情）。

通用 Butano 解码器本身支持三字节 UTF-8。然而把真正的三字节中文直接交给本游戏的角色对话路径，会在开场转入场景时卡住；同样内容使用两字节字码后可正常运行。确切的上层解析/缓冲缺陷尚未精确定位。因此 ROM 使用 U+0100 起的两字节 UTF-8 别名，字体把这些别名显示成汉字，字码映射见 `analysis/code_map.json`。译文源文件仍是可直接编辑的正常中文。通用 Butano 解码器保持原样。另修复游戏自定义富文本字宽函数：它原来只识别17个葡语重音字，其他Unicode统一按7px推进，导致第二行和逐字对话中的12px汉字挤在一起。补丁在ROM偏移0x1663c将未知非ASCII字宽回退从7px改为12px（0720→0c20），原有17字的宽度表及ASCII路径保留。已以模拟器实际OAM坐标确认第二行推进由7px改为12px，并逐项对照17个原字宽返回值不变。

文本迁移同时处理 `string_view` 的起始/结束指针，只有匹配的成对指针一起更新；物品表是固定34字节字段，直接在字段中重排，保留整个数组基址和结构，绝不把数组首名当普通字符串迁走。

## 复现

在包含原始 ROM 的本目录运行：

```sh
python3 tools/build_zh.py
python3 tools/check_runtime.py --qa
python3 tools/qa_widths.py
```

构建需要 Python 3；图像步骤需要 Pillow，运行验证需要本工作区已有的 mGBA 0.10.5 core / 测试桥。`--utf8-three-byte` 是故障对照诊断选项，不能用于交付版本。不要将诊断版本误当可玩版本。

## 验证边界

实际模拟器验证使用全新测试 SRAM，涵盖开场、角色独白、八页教程、操作图示、实际场景、六页Start菜单、物品分类与返回场景；静态校验全部字形、字宽、字码与文字指针，BPS 另作解码重建校验。本轮另记录16段菜单/场景切换、共2400连续帧并抽查帧序列；Start进入菜单的第6、7帧为纯色，原版与补丁一致，属于原有转场。测试序列未观察到新增持续闪烁或乱码。完整通关、所有任务分支、商店长列表、逐项物品说明及实机性能尚未逐一游玩验证。原游戏本身尚在开发，原版明确提示尚未开放的内容仍保持原有边界。
